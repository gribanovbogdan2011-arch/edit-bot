EDIT BOT — оплата Telegram Stars

Цена: 100 Telegram Stars (XTR).
После подтверждённой оплаты бот отправляет покупателю @Gggjcfhbdtj.

Запуск в Termux:
1. Установи зависимости: pip install -r requirements.txt
2. Задай BOT_TOKEN локально в Termux (не отправляй его никому).
3. Запусти: python bot.py

Важно:
- Для цифровых товаров в Telegram используется Telegram Stars.
- Не публикуй токен и отзывай токены, которые уже попадали в переписку или скриншоты.
- Бот работает, пока запущен процесс Termux или сервер.
